办公协作需要让讨论形成任务，让任务引用共同可见的资料，让交付物和产生它的上下文能够被复核。本版将这些行为放进同一会话：人和 Agent 通过相同消息、任务与文档 API 工作；Agent 的自动参与额外受可见策略、运行租约、版本检查和因果预算约束。

文档仍是共享工作载体。会话契约、任务状态、消息、共享文档、模型调用前的精确上下文和交付结果均可检查，整个会话可导出 Markdown。JSON 文件保存身份哈希、游标和持久化记录，不引入模型专属的隐形业务记忆。

本系列提供 `/im` 办公入口，覆盖工作会话、成员管理、共享任务、文档编辑、Agent 参与控制和运行记录。后续迭代已增加日历、会议、附件、密码账号、内部邮件、考勤/审批及插件目录，Flutter 客户端的各平台构建与界面证据另见发布记录。“超越飞书”仍是长期产品方向，当前实现不等同于成熟办公套件或生产规模。

[协议与运维](PROTOCOL.md) 、[基础 IM / Agent 商店补充](BASE_IM_AND_STORE.md) 与 [会议、日历和附件协议](OFFICE_MODULES_AND_ATTACHMENTS.md) 给出准确 API、权限、事件恢复、上下文预算、故障恢复及已知边界。配套 [Active Agent 分支](https://github.com/huapohen/active-agent/tree/equal_rights) 提供执行器与本地启动工具；实现提交、时间和验证证据由发布清单关联，避免将规划写成已完成验证。
