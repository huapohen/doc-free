## 日历

手机默认三日时间轴，提供日、三日、周、月切换；月份标题再次点击收起内联六周选择器。回到今天同时恢复日期与时间位置。桌面有侧栏月历、日/周/月视图与真实会话筛选。日程搜索使用实际标题、描述与地点；仅我参与过滤依据实际参与者。

时间轴覆盖 00–24，跨天事件按日截取，按本地钟表时间排布；重叠事件按相交时间组分列，后续不重叠事件恢复全宽。月格根据实际高度和字体缩放计算可见事件数，余项以 +n 打开当天完整列表。

创建与编辑沿用真实 API，保存来源会话，人和 Agent 共用参与者选择与 RSVP。身份、服务地址、会话或权限改变后，旧表单不能继续执行。会话 owner 判断依据实际成员角色及服务端创建者契约，未依赖不存在的角色投影字段。

手机创建页改为白底、独立起止时间、无框主题和明确字号；时区显示计算得到的 GMT 偏移。桌面创建页双列，右侧为真实当日日程卡片，尚未实现飞书完整的空闲时间轴预览。

仍缺全天、重复、农历、会议室、预约活动、拖拽改期与完整可用时间预览。
