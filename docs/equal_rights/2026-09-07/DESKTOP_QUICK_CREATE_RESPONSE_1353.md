## “打开慢”的两个来源

源码检查确认当前 Flutter `showMenu` 默认动画为 300ms，并对条目逐个淡入。本轮显式改为 90ms；系统 `disableAnimations` 时使用 `AnimationStyle.noAnimation`，首帧完整显示。

原 `_opening` 锁还覆盖了 `await onSelected(...)`。选中动作一旦等待服务器或另一个页面，菜单已经消失但 + 按钮仍锁住。现在弹窗锁仅覆盖菜单路由，选择后的异步动作独立执行；前一动作未完成时也能重新打开 + 菜单。

打开菜单只读取本地动作常量、同步权限回调和布局信息，构造路径没有网络等待。实际动作的 API 处理仍在壳与状态层，不能把菜单 90ms 动画当成后端执行耗时。
