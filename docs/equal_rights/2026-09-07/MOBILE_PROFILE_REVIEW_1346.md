## 发现并修复

回归基线 14 项通过、4 项失败，定位到两个实际问题：

1. 身份、服务地址或身份代次切换后，已捕获的旧按钮回调仍会返回 `settings` 等动作。现在每次派发前校验打开面板时的状态对象、服务地址、身份 ID 和代次，并保持一次失效后锁定。管理权限被撤销时，旧企业管理回调也不再派发。
2. 父级替换整个 `OfficeState` 对象时，面板没有解绑旧监听，也没有清除旧身份上下文。现在 `didUpdateWidget` 解绑旧对象、绑定新对象并永久使该面板失效；卸载后不会遗留监听。

桌面复制身份 ID 也使用相同身份检查，复制完成后的提示不会在身份已切换时弹出。身份失效页增加安全区与滚动，避免提示进入手机刘海区。
